# Defeat AI

A collaborative PWA Mini App for the World App ecosystem.

## Overview
- **Platform:** World App (Mini-App) & Web PWA
- **Network:** World Chain (L2)
- **Tech Stack:** Vue 3, Nuxt 3, Tailwind CSS, MiniKit JS, Netlify Blobs

## Gameplay Mechanics
- **1 Free Hit every 24h** per verified human (World ID).
- **Power Strike:** Pay 2 WLD for instant additional strikes.
- **Boss Scaling:** Level 1 (50 HP), Level 2 (100 HP), Level 3 (200 HP), etc.
- **Rewards:** Community crypto token rewards distributed upon defeating each boss.
